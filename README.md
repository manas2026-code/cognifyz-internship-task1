\# Cognifyz Internship - Task 1



\## Project Title

Student Registration Form



\## Description

This project is created as part of Task 1 of the Cognifyz internship.



The project demonstrates:

\- HTML form creation

\- Node.js and Express server

\- Form submission using POST

\- EJS server-side rendering



\## Technologies Used

\- HTML

\- Node.js

\- Express.js

\- EJS



\## How to Run



1\. Install Node.js.

2\. Open the project folder in the terminal.

3\. Install dependencies:



npm install



4\. Start the server:



node server.js



5\. Open the browser and visit:



http://localhost:3000



\## Features

\- Student name input

\- Email input

\- Form submission

\- Displays submitted information
